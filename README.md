# OBS Streaming Template

A local OBS template that automatically arranges seven independent panels in a bento grid. Cameras, chat, captions, and other content stay beside the game instead of covering it.

## Status

Under development. This repository is the new home for version control and ongoing verification. The runnable package has not been published yet; cross-platform checks and third-party asset review are still in progress.

## Intended workflow

Download a release ZIP, extract it, configure the panels locally, and apply the layout in OBS. No always-on hosted service is required for the template itself. External widgets may require their own services.

Each panel can be configured independently for an OBS source, a web address, or image/video content. Personal widget links and local settings do not belong in this repository.

## Feedback

Use GitHub Issues for bugs and feedback. Do not include private widget links, access tokens, or personal configuration files.
