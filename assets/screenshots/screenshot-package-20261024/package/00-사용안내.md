## 사용 시 지켜야 할 범위
- 7개 이미지는 실제 픽셀을 검토했습니다. 육안상 이메일·결제정보·API 키·토큰은 발견하지 않았습니다. 실제 방송 원본에는 공개 채널 주소·닉네임·게임 내 사용자명이 보입니다.
- 방송 원본은 자르기·보정 없이 보존했습니다. 전체 PNG는 브라우저 UI 포함 2048×1113으로 정확한 16:9가 아닙니다. 화면 비율을 임의로 늘려 맞추지 마세요.
- 이전 사용자 선택본과 중복 HTML 캡처는 ZIP에서 제외했습니다. 이전 사용자 원본은 삭제하지 않았습니다.
- 성과 수치, 사용자 수, 시간 절감, 성능 향상, 자동 감지 성공을 새로 만들지 마세요. 정지 화면은 동작 전 과정이나 성능을 입증하지 않습니다.
- 역할은 코드 작성 AI / 설계·판단·검수 사용자로 정직하게 기재하세요.
- 현재 방송·OBS·기존 Chrome·게임·음악·설정·제품 코드에는 손대지 않았습니다. HTML 캡처만 별도 headless 브라우저의 일회성 컨텍스트에서 수행했습니다.

## 빠진 자료와 한계
- 0.10.4 OBS Scripts에 Lua가 등록되고 적용 완료된 최신 설정 창 캡처는 없음. 현재 OBS를 조작하지 않고 과거 QA 화면으로 보완했습니다.
- 별도 Overlap HTML 설정 화면, 설정 ZIP 내보내기·압축 해제 과정 캡처는 이 패키지에 없음. 가이드의 설명용 그림이 그 절차를 안내합니다.
- HTML 전체 페이지 캡처가 아니라 첫 화면입니다.
- 0.10.4 표시와 실제 두 방송 레이아웃은 확인했지만 개별 위젯의 데이터 정확성·자동화·성능·장시간 안정성은 검증하지 않았습니다.
