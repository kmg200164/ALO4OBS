Figma `design-system` 페이지에 새 화면을 그리기 전에 **어떤 기능이 필요한지** 먼저 고르는 초안이다. 현재 코드(`template/settings.html`, `preview.js`)와 [10/30 결정](obsidian://open?vault=second-brain&file=archive%2Fadr%2F2026-10-30-alo4obs%EB%8A%94-bento%EC%99%80-overlap%EC%9D%84-%ED%95%A9%EC%B9%98%EA%B3%A0-ui-%EC%83%89%EC%9D%80-%EC%95%8C%EB%A1%9C%EC%97%90-%ED%95%98%EB%82%98%EC%99%80-%EC%8B%9C%EC%8A%A4%ED%85%9C-%EB%9D%BC%EC%9D%B4%ED%8A%B8-%EB%8B%A4%ED%81%AC%EB%A7%8C-%EC%93%B4%EB%8B%A4)에서 뽑았다. 빠진 기능이 있을 수 있다. 명기가 줄을 지우고 더해서 확정하면, 필요한 아이콘은 이 목록에서 저절로 추려진다.

표기: **유지**는 그대로, **뺌**은 10/30 결정으로 없앰, **새로**는 결정으로 생김, **검토**는 명기가 정해야 함. 아이콘은 Lucide 이름 후보이며 v1.65.0에 있는지는 Figma 플러그인에서 확인한다.

**버튼 표기 원칙(명기 확정 2026-10-30):** Figma `user-flow`에 한글로 적은 버튼 이름은 전부 **아이콘 버튼**이 되고, 그 한글은 **마우스 호버·키보드 포커스 때 뜨는 툴팁**이다. 버튼에는 글자를 쓰지 않는다. 툴팁 문구는 `aria-label`과 같은 이름이다(지금도 같은 방식). 이름·버전처럼 글자 자체가 정보인 것은 버튼 아이콘 대상이 아니다.

## 설정 화면 — 위쪽 도구

| 기능 | 상태 | 아이콘 후보 |
|---|---|---|
**Figma `user-flow`에서 확정한 4개 버튼(설정 영역 위, 10/30):**

| 기능 | 상태 | 아이콘 후보 |
|---|---|---|
| **되돌리기:** 사용자가 남긴 임시 저장 시점이 미리보기 화면과 함께 시간순으로 뜨고, 원하는 시점을 고르거나 초기화를 고른다 | 확정, 이전의 "프리셋 적용 취소"와 "전체 초기화"를 대체 | `undo-2`, `history` |
| **임시 저장:** 사용자가 원하는 시점에 지금 상태를 남긴다. 자동 저장은 그대로 두고 목록에는 섞이지 않는다 | 확정 | `save` |
| **다운로드:** 내 프리셋(`script.lua`)으로 받는다 | 확정 | `download` |
| **업로드(불러오기):** 남이 만든 또는 과거의 내 프리셋(`script.lua`)을 올린다 | 확정 | `upload` |
| 기본 프리셋 고르기 버튼 | **없음.** 처음 들어왔을 때의 초기 설정이 기본 프리셋이고, 되돌리기의 "초기화"가 그 상태로 돌아간다 | |
| 초기 설정(합친 뒤 하나) | 대부분의 스트리머에게 맞는 모양으로 Figma에서 정함 | |

## 아이콘 후보 요약

- 현재 사이트 18개 중 이어서 쓰는 것: `menu`, `bug`, `heart`, `settings`, `book-open`, `languages`, `maximize`, `rotate-ccw`, `save`, `triangle-alert`, `trash-2`, `plus`, `folder-open`.
- 빠지는 것: `github`, `sun`, `moon`, `palette`, `arrow-left-right`(레이아웃 전환), `rotate-cw`.
- 새로 후보: `upload`, `download`, `undo-2`, `layout-grid`, `square-dashed`, `droplets`, `image`, `video`, `link`, `eye`, `eye-off`, `info`, `check`, `chevron-down`, `external-link`, `arrow-up-down`, `panel-left`, `panel-right`.
- 합치면 약 30개 안팎이다. 이 정도면 플러그인으로 하나씩 넣어 컴포넌트로 만드는 방법(`Icon/이름`)으로 충분하다.

## 아직 모르는 것

- 현재 코드에서 뽑았고 화면을 직접 열어 전부 확인한 것은 아니다. 숨은 설정이 있을 수 있다.
- 합친 뒤의 구조(Main·Sub·Side와 5열 격자)는 [[notes/planning/bento-overlap-통합-영향-목록|통합 영향 목록]]의 모델 후보 A/B/C 중에서 정한다.
