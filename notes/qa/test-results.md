## Public 공개 전 독립 QA — 2026-10-04

**판정: 공개 준비 미완료. 코드·패키지 검증은 부분 완료이며, 실제 화면 QA는 미검증이다.** 기존 구현자의 완료 주장과 과거 테스트 결과를 통과 근거로 사용하지 않았다. 소스 조사·수정을 분담하고 메인이 변경 코드와 실행 결과를 별도로 확인했다.

### 발견하고 수정한 문제

- 영어 도움말의 손상된 문구와 CHANGELOG 링크. 설정 오류·테마 버튼·그라디언트 중지점의 한국어/영어/일본어 접근성 안내.
- 카메라 장치 새로고침이 연결 대기 상태를 덮는 경합.
- 커스텀·홍보 패널 비활성화 후 영상·웹 위젯 연결이 계속 남는 문제. 동일 URL 재활성화 복원도 검사.
- 그라디언트 중지점 위치 교차 후 잘못된 구간에 새 중지점 추가. 최초 Gradient 선택의 미리보기 반영 지연.
- 추출한 버전 3 config.js를 편집 화면이 읽지 않던 문제. 새 설정 파일은 이전 브라우저 초안보다 우선하며, 초기화는 중립 기본값을 유지한다.
- 늦게 끝나는 파일 읽기가 초기화·새 선택을 덮는 문제. ZIP 생성 중 초기화·새 파일 선택으로 설정과 포함 자산이 어긋나는 문제.
- 배치 옵션 행 내부 간격 10px → 8px.
- 비활성 OBS 패널의 과거 소스·마스크·URL이 전체 Apply를 막는 문제. 활성 패널의 검증은 유지.
- 데모와 Source README의 개인명 중립화, 개인 설정 ZIP·커스텀 업로드·생성 마스크의 Git 제외 규칙 누락.
- 배포 빌드의 HTML 내부 CSS·정적 JavaScript 자산 참조 검사 누락. ZIP 선검증·임시 파일 검증 후 교체로 기존 전달 파일 보존.

그라디언트 색상 버튼 비정사각형 후보는 기존 header.css의 32×32 규칙을 확인한 뒤 기각했다. 해당 후보의 CSS 변경은 남기지 않았다.

### 개인정보·라이선스·공개 차단

- config.public.js는 중립 초기화/배포 정본이고 최종 ZIP의 config.js와 바이트가 같다. Source/config.js는 개인 실행 설정으로 Git 추적과 과거 이력에 남는다. ignore 추가만으로 이미 추적된 파일이나 이력은 제거되지 않는다.
- 프로젝트 과거 텍스트 114개와 ZIP 이력 6개를 조사했다. 전형적 토큰·URL credential·개인 절대 경로 패턴 후보는 발견하지 못했지만 비밀값 부재를 보증하지 않는다. 과거 ZIP 3개에는 개인 데모명 표식이 남는다. 원문 값은 보고하지 않는다.
- 현재 Git root는 개인 external_brain Vault이며 별도 공개 프로젝트 repository는 없다. Vault 전체 파일·이력을 공개 대상으로 사용하면 안 된다. 별도 공개 파일/이력 선택은 사용자 승인 뒤 필요하다.
- 프로젝트 코드 LICENSE 미선택. 게임 배경·대회 로고/파생 카드·손캠 이미지·목업·플랫폼 favicon·여러 Figma 아이콘 및 인라인 SVG의 공개 재배포 권한 미확인. 파일별 근거는 asset-sources에 있다. Inter OFL 및 확인된 Lucide 고지는 다른 자산 전체의 권리를 증명하지 않는다.
- build.py의 gift allowlist를 public allowlist로 바꾸지 않았다. 권리 미확인 자산은 현재 선물용 ZIP에 계속 포함되며 공개 가능한 패키지로 판정하지 않는다. 파일 삭제·Git 이력 재작성·repository 생성·commit/push·공개·배포를 수행하지 않았다.
