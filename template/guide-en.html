Configure and connect OBS

Once this page is open, follow these steps to configure the layout and apply it in OBS.

1. Set up the Main, Sub and Side panels

The seven slots are Main, Sub 1–3 and Side 1–3. None of them is locked to a game, chat, or camera. For each panel, choose None, OBS source, Web URL, or Image/Video, then set its style. Panel names help identify slots in the preview and are hidden from OBS output. Samples do not connect real accounts.

Main and Sub 1–3 sit in the left frame; Side 1–3 fill the right frame from top to bottom. Main is always enabled. Use the Number of Sub panels and Number of Side panels sliders to choose 1, 2 or 3 each. Sub panels fill from the left and Side panels from the top. You can only swap Main and the Sub row up or down.

Spacing in Global settings sets both the gap between panels and the margin at the screen edges: Extra narrow 8 px, Narrow 16 px, Medium 24 px, Wide 32 px (default) or Extra wide 48 px. The right frame stays 440 px wide and the left frame uses the rest.

Choose Auto or Manual for the height of Side 1–3 and for the width of Sub 1–3. Main and Side panels always use automatic width. Auto fills remaining space. Manual keeps the pixel size entered with the number input or slider. Limits update with the active panels, spacing and other manual sizes. When every enabled Sub is Manual and their widths do not match the frame, nothing is resized: a warning about empty space or overflow appears next to the Sub width setting. Saving and applying in OBS still work; on an overflow the Sub widths shrink to fit on screen.

Uploaded images and videos are restored when you reopen the same settings page in the same browser. Save a settings ZIP before clearing browser data or moving files.

Sub panels have a minimum width based on their 16:9 reference row height (206 px by default). Other minimums remain 50% and maximums 150% of the automatic size, subject to frame boundaries and peer space. Sub panels use automatic height. Main offers Auto, 16:9 (default), 21:9, and 32:9. Auto fills the height remaining above or below the Sub row. Drag near a 1:1 or 16:9 mark to snap to that ratio; marks are recalculated from the other dimension. Numbers and keyboard controls remain precise.

2. Review the preview and save the settings ZIP

Changes appear in the preview automatically. Review it, then click Save as ZIP. The downloaded file is OBS-settings.zip.

3. Extract your OBS package

Extract OBS-settings.zip into a new folder. It includes your settings, media and OBS-script.lua. Keep this folder in place.

4. Apply automatic layout in OBS

  • Set the base canvas to 1920 × 1080.
  • Open Tools → Scripts → + and select OBS-script.lua in the folder you just extracted from OBS-settings.zip.
  • For each panel set to OBS source, choose an existing source in the selector with that panel's name (Main, Sub or Side). You cannot choose the same OBS source for two panels.
  • If the script controls appear in Korean, enable English UI (reload after changing) and reload the script.
  • Click Apply saved settings / Auto layout.

More help

Where do I get a web widget URL?

Copy the OBS display URL from any chat, translation, alert, donation, or other widget provider. Paste it into Web URL on the panel you choose. A provider's settings-page URL may differ from its display URL. Configure the widget's own fonts, colors, audio, and running state with its provider.

A private token may be embedded in a widget URL; keep your settings ZIP private.

How do I use an OBS source or image/video?

First create an individual video source in OBS, such as a capture, camera, or media source. Scenes and groups cannot be selected as panel sources. Set your chosen panel to OBS source, then choose it in that panel's numbered script selector. One OBS source cannot be selected twice. For a file, choose Image/Video and upload it or enter a direct media URL. An ordinary video watch-page URL is not a media-file URL.

How does the frame structure, corners and OBS positioning work?

The left and right frames and the spacing setting place the seven panels without manual pixel coordinates. Moving a template item in OBS is temporary: the next Apply restores the saved layout. Original OBS sources remain intact; alpha masks are applied to template-managed groups. Applying the same settings again does not duplicate template sources.

The preview is blank or OBS shows old settings
  • A browser may block some local file access in the preview. You can still enter settings and save the ZIP; verify in OBS.
  • Extract the latest settings ZIP next to the script and apply automatic layout again. Refresh the OBS browser-source cache if needed.
  • For web widgets, check that you used the OBS display URL. A stopped program or offline channel may show nothing.
Can I share my settings links?

Widget URLs may contain private tokens. Do not post settings files or ZIPs in public repositories or chats.
