설정과 OBS 연결

이 화면을 열었다면 아래 순서대로 설정하고 OBS에 적용하세요.

1. 패널 1~7 설정

화면의 일곱 칸은 게임·채팅·캠 같은 용도로 고정되지 않습니다. 각 패널을 골라 없음 · OBS 소스 · 웹 주소 · 이미지/영상 중 하나를 정하고 상위·하위 프레임 위치와 스타일을 설정하세요. 미리보기의 패널 번호는 OBS 화면에 나오지 않습니다. 샘플은 실제 계정에 연결되지 않습니다.

패널 5·6·7의 높이와 패널 2·3·4의 너비를 자동 또는 수동으로 선택할 수 있습니다. 패널 1·5·6·7의 너비는 항상 자동이며 조절 항목이 표시되지 않습니다. 자동은 남은 공간을 채우고, 수동은 숫자 입력이나 슬라이더로 정한 픽셀 크기를 유지합니다. 활성 패널·간격·다른 수동 크기에 따라 입력 한도가 갱신되며, 범위를 벗어나면 가장 가까운 한도로 보정됩니다.

업로드한 이미지·영상은 같은 브라우저에서 같은 설정 페이지를 다시 열면 복원됩니다. 브라우저 데이터를 지우거나 파일을 옮기기 전에 설정 ZIP을 저장해 두세요.

상위 프레임은 왼쪽 3칸·오른쪽 1칸을 유지합니다. 허용 범위는 현재 배치의 자동 크기(50~150%), 상위 프레임 경계와 다른 패널의 최소 공간에 따라 달라집니다. 패널 2·3·4의 높이는 자동으로 정해집니다. 패널 1은 화면 비율에서 자동·16:9(기본)·21:9·32:9를 선택합니다. 자동은 남는 높이를 채우며, 패널 2~4를 모두 끄면 왼쪽 상위 프레임의 높이를 꽉 채웁니다. 비율을 선택하면 해당 비율을 유지합니다. 다른 축의 크기로 계산한 1:1·16:9 눈금 가까이 드래그하면 해당 비율에 맞춰집니다. 비율은 패널 1을 포함해 모두 선택 사항입니다. 숫자 입력과 키보드는 정확한 값을 그대로 사용합니다.

2. 미리보기 확인 후 설정 ZIP 저장

변경 사항은 미리보기에 자동 반영됩니다. 확인한 뒤 ZIP 파일로 저장을 누릅니다. 설정 ZIP은 OBS-settings.zip으로 저장됩니다.

3. OBS 적용 파일 압축 해제

OBS-settings.zip을 새 폴더에 압축 해제하세요. 설정·이미지·OBS-script.lua가 함께 들어 있습니다. 이 폴더를 보관하세요.

4. OBS에서 자동 배치 적용

  • 기본 캔버스를 1920 × 1080으로 설정합니다.
  • 도구 → 스크립트 → +에서 방금 압축 해제한 OBS-settings 폴더에 있는 OBS-script.lua를 추가합니다.
  • 콘텐츠가 OBS 소스인 패널마다 해당 번호의 선택기에서 기존 소스를 고릅니다. 같은 소스를 두 칸에 중복 선택할 수 없습니다. 일곱 칸을 모두 캠으로 쓰려면 서로 다른 OBS 캠 소스 일곱 개가 필요합니다.
  • 저장한 설정 / 자동 배치 적용을 누릅니다.

추가 안내

웹 위젯 주소는 어디서 가져오나요?

채팅·번역·후원 등 원하는 서비스에서 OBS 표시용 위젯 URL을 복사해 원하는 패널의 웹 주소에 입력합니다. 서비스의 설정 화면 주소와 표시용 주소는 다를 수 있습니다. 위젯 내부 글꼴·색·소리·작동은 제공자에서 설정하세요.

개인 위젯 URL에는 토큰이 들어갈 수 있으므로 설정 ZIP을 공개하지 마세요.

OBS 소스와 이미지·영상을 쓰려면?

OBS에 캡처·카메라·미디어 같은 개별 영상 소스를 먼저 만듭니다. 장면과 그룹은 패널 소스로 선택할 수 없습니다. 해당 패널을 OBS 소스로 설정하고 스크립트에서 그 패널 번호의 소스를 선택하세요. 같은 OBS 소스를 두 칸에 중복 선택할 수 없습니다. 파일은 패널의 이미지/영상에서 올리거나 직접 미디어 URL을 입력합니다. 일반 동영상 시청 페이지 주소는 미디어 파일 주소가 아닙니다.

프레임 구조, 모서리, OBS 위치는 어떻게 동작하나요?

상위·하위 프레임이 일곱 패널의 위치를 정하므로 숫자 좌표를 직접 편집하지 않습니다. OBS에서 직접 옮긴 위치는 다음 자동 배치 때 저장된 배치로 돌아옵니다. 원본 OBS 소스는 보존되며 투명 모서리용 알파 마스크는 템플릿 전용 그룹에 적용됩니다. 같은 설정을 재적용해도 템플릿 소스가 중복 생성되지 않습니다.

화면이 비거나 이전 설정이 보여요
  • 브라우저가 로컬 파일 접근을 막으면 일부 미리보기가 비어 있을 수 있습니다. 입력과 ZIP 저장은 계속 가능하며 OBS에서 확인하세요.
  • 최신 설정 ZIP을 스크립트와 같은 폴더에 다시 풀고 자동 배치를 적용합니다. 필요하면 OBS 브라우저 소스 캐시를 새로고침합니다.
  • 웹 위젯은 OBS 표시용 주소인지 확인합니다. 제공자의 채널이나 프로그램이 꺼져 있으면 비어 있을 수 있습니다.
개인 링크를 공유해도 되나요?

위젯 URL에는 비공개 토큰이 들어갈 수 있습니다. 설정 파일과 설정 ZIP을 공개 저장소나 채팅에 올리지 마세요.
