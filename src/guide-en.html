Configure and apply in OBS

Windows OBS 32: Composite Blur — the panel background blur plugin is included. Close OBS and run composite-blur-install.cmd once beside settings.html at the top level of the extracted ZIP. No separate download or manual copying is needed. Windows x64 OBS 30–32 and 33 select their matching bundled payload. macOS uses composite-blur-install.command; native Debian/Ubuntu amd64 uses composite-blur-install.sh. Review OS permission and dependency prompts yourself. Actual macOS/Linux installation validation and the offline Flatpak extension are still pending.

Follow the picture first. Open the headings below when you need the details.

Bento arranges panels side by side; Overlap places them above full-screen Main. Choose a layout to start. Bento panels blur the independently configured full-canvas background image or color. Overlap panels blur Main, retaining the static backdrop while capture is unavailable.

Quick start

The extracted personal ZIP has script-bento.lua or script-overlap.lua at its root. Keep its files/bento/ or files/overlap/ folder next to the script.

Required setup

1. Prepare OBS

Use OBS Studio 30.1 or newer with Browser Source and Tools → Scripts available.

In Settings → Video, use a 1920 × 1080 base canvas. If your production profile uses another size, choose or create a separate profile for this setup; do not arbitrarily change your production profile.

2. Open the distribution

Extract the entire ALO4OBS-v0.10.4.zip distribution, then open its root settings.html (it opens files/settings.html). Do not open pages inside the ZIP.

3. Choose panels and content

In Bento select Main, Sub 1–3 or Side 1–3; in Overlap select Main or Panel 1-1 through Panel 5-3. In Content type, choose None, OBS source, Web URL, or Image/video. These roles are not fixed to games, chat or cameras.

For OBS source, first create an individual capture or camera source in OBS and check that it works. Scenes and groups are not panel source choices. For Web URL, enter the provider’s OBS display URL; for Image/video, upload a file or enter a direct media URL. A watch-page URL is not a media file.

4. Set layout and style

In Bento, set panel counts, Main/Sub row order, Side position, sizes and spacing.

In Overlap, set visibility and panel count (1–3) per column. Enable Wider width on column 1, 3 or 5 to use the 3-column basis instead of the 5-column basis; adjacent columns are disabled. Panels stay in their named column. Height Auto shares remaining space; Manual sets pixels. Panel position Auto aligns the column stack at the top, center or bottom; Manual stores the desired Y coordinate. Height is at least 128 px; applied positions and heights are constrained to preserve panel order, outer margins and panel gaps. After other settings change, applied Y may differ from saved Y. Drag vertically in the preview to switch to Manual position. Hidden panels retain their settings. The safety guide is preview-only and varies by game; red/yellow warnings do not block placement.

Use Switch layout on the right of the header to change layouts. Each layout and its panel settings are retained; Main content and global appearance are shared. Check the preview for layout. View your actual OBS source video in OBS.

5. Save and extract your personal ZIP

Click Save as ZIP. The result is Settings-Bento.zip / Settings-Overlap.zip, your personal application package. It is different from the distribution ALO4OBS-v0.10.4.zip.

Extract all of Settings-Bento.zip / Settings-Overlap.zip into a new permanent folder. Keep script-bento.lua or script-overlap.lua (named for your layout), JSON configuration, masks, assets/ and runtime files together. The script reads relative to its own folder; moving only the Lua file breaks those paths. The runtime package is for OBS and does not contain the settings editor.

6. Connect OBS and check the result

In OBS, open Tools → Scripts → + and select the script for your layout, script-bento.lua or script-overlap.lua, from that extracted personal folder. If you use both layouts, you can extract them into the same folder and add both scripts; their different names keep them apart in the OBS Scripts list.

For each OBS source panel you want to display, select the matching original source in its matching panel script selector. Use distinct sources for different panels. A blank selector can intentionally leave a panel empty. Click Apply saved settings / Auto layout.

Open the generated ALO4OBS · BENTO or ALO4OBS · OVERLAP scene. Only the exported layout’s scene is created or updated. To use both, export each layout and Apply each once. Check capture, camera, widgets and media in OBS before using the scene for a broadcast. Browser edits do not automatically update OBS: export again, extract the whole package, register the new script path or update the application folder and reload, check selectors, then Apply again.

Extra tips

Layout controls

In Bento, by default, Main and Sub 1–3 sit in the left frame; Side 1–3 fill the right frame from top to bottom. Main is always enabled. Use the Number of Sub panels and Number of Side panels sliders to choose 1, 2 or 3 each. Sub panels fill from the left and Side panels from the top. Use the Swap Main and Sub rows switch to reverse their vertical order. Turn on Place Side column on the left to move the entire Side column to the left and the Main/Sub frame to the right. Side 1–3 keep their top-to-bottom order.

Spacing in Global settings sets both the gap between panels and the margin at the screen edges: Extra narrow 8 px, Narrow 16 px, Medium 24 px, Wide 32 px (default) or Extra wide 48 px. The Side frame stays 440 px wide on either side; the Main/Sub frame uses the rest.

Choose Auto or Manual for the height of Side 1–3 and for the width of Sub 1–3. Main and Side panels always use automatic width. Auto fills remaining space. Manual keeps the pixel size entered with the number input or slider. Limits update with the active panels, spacing and other manual sizes. When every enabled Sub is Manual and their widths do not match the frame, nothing is resized: a warning about empty space or overflow appears next to the Sub width setting. Saving and applying in OBS still work; on an overflow the Sub widths shrink to fit on screen.

Uploaded images and videos may be restored when you reopen the same settings page in the same browser. Save a settings ZIP before clearing browser data or moving files.

Sub panels have a minimum width based on their 16:9 reference row height (206 px by default). Other minimums remain 50% and maximums 150% of the automatic size, subject to frame boundaries and peer space. Sub panels use automatic height. Main offers Auto, 16:9 (default), 21:9, and 32:9. Auto fills the height remaining above or below the Sub row. Drag near a 1:1 or 16:9 mark to snap to that ratio; marks are recalculated from the other dimension. Numbers and keyboard controls remain precise.

OBS versions and verification scope

The script uses obs_sceneitem_get_info2 / obs_sceneitem_set_info2, introduced in OBS Studio 30.1. Apply and reapply for Bento and Overlap were checked in an isolated Windows OBS 32.2.2 environment. macOS, real captures/cameras, personal widgets and broadcast output remain unverified; check them in your own setup.

Update an ALO4OBS installation

Export your OBS scene collection, back up the entire old application folder, and record every script source selection before updating. Keep old packages intact; extract the new distribution into a separate folder.

The editor reads config.js, not JSON imports. After a successful old-script Apply, copy its generated config.js (in files/bento/ or files/overlap/ for type-specific packages) into the new distribution’s files/ folder. Copy only personal media referenced by its assets/... paths, preserving those paths. Keep the new config.public.js, internal scripts and fonts. If config.js is missing, return to the old version and Apply once to generate it, or manually reconfigure while keeping the old environment. Renaming JSON is not an import. A browser draft at a new path is not guaranteed.

Open the new root settings.html, check values and media, export a new Settings-Bento.zip / Settings-Overlap.zip, and extract it into a new permanent folder. After recording mappings, remove only the old Lua registration (this does not delete scenes). Earlier packages named this script OBS-script.lua; new packages use script-bento.lua or script-overlap.lua depending on the layout. Do not keep the old-name registration in the Scripts list; add the file with the new name. Add the new Lua path and reselect the original sources before Apply; a new registration does not inherit old selector values from JSON.

Move from legacy OST

Keep the old OBS Streaming Template scene, OST · groups, originals and complete script folder. Export the scene collection and record source selections. Stop/remove only the old script registration, retaining its Lua file and backup. Configure the new version with the same originals, add its script, reselect sources and apply.

The new ALO4OBS · BENTO or ALO4OBS · OVERLAP scene is created separately. Existing ALO4OBS and OST scenes are not migrated automatically. Verify before switching and retain the old scene for recovery. Do not blanket-delete sources or groups.

Rollback and verification limits

Apply reuses the selected type’s ALO4OBS · BENTO or ALO4OBS · OVERLAP scene and sources/groups starting with that scene name. Original source settings and filters are retained; generated scene-item transforms and layout are reapplied from saved settings.

To roll back an update, import the pre-update scene-collection backup into a separate recovery collection, restore the matching Lua and complete application folder, and check original source mappings. Reapplying the same type updates its scene and generated browser-source local_file paths; registering old Lua alone does not restore the previous state. If an old single ALO4OBS or OST scene remains separate, verify it before switching back. Full recovery after a real failure, macOS and native file-picker behavior remain unverified.

Reserved names and shared sources

Generated source/group names start with ALO4OBS · BENTO · or ALO4OBS · OVERLAP ·. Reusing them in other scenes shares their updated content. Original sources from disabled groups remain as hidden root items. If Apply reports a reserved-name collision, inspect the item and restore your backup if needed; do not blindly delete unrelated sources.

Where do I get a web widget URL?

Copy the OBS display URL from any chat, translation, alert, donation, or other widget provider. Paste it into Web URL on the panel you choose. A provider's settings-page URL may differ from its display URL. Configure the widget's own fonts, colors, audio, and running state with its provider.

How does the frame structure, corners and OBS positioning work?

In Global settings, Corner radius is independent of spacing: choose 8, 16, 24, 32 or 48 px. Corner smoothing offers 0%, iOS 60% or 100%. Fresh Windows settings default to 0% and fresh macOS settings to 60%; saved choices take precedence. Turn on Enable shadow in Global settings and select one of five strengths. Enable Override global settings on a panel to adjust its shadow alongside fill and stroke. Otherwise it inherits the global shadow, while the stored local value remains available. Full-screen Overlap Main does not use a shadow.

Positions moved manually in OBS return to the saved layout on the next Apply. Original OBS source settings are designed to be preserved; alpha masks are applied to template-owned groups. Reapplying the same settings does not create duplicate template sources.

The preview is blank or OBS shows old settings
  • A browser may block some local file access in the preview. You can still enter settings and save the ZIP; verify in OBS.
  • Export a new settings ZIP, extract the whole package, register the new path or update the application folder and reload the script, check source selections, then apply automatic layout again. Refresh the OBS browser-source cache if needed.
  • For web widgets, check that you used the OBS display URL. A stopped program or offline channel may show nothing.
Can I share my settings links?

Widget URLs may contain private tokens. Do not post settings files or ZIPs in public repositories or chats.
