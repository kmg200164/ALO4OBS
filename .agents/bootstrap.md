## Layout (DANS)

| path | role |
|---|---|
| `docs/` | durable docs |
| `notes/` | notes, meetings, kept drafts |
| `src/` | code / implementation |
| `assets/` | media, binaries |
| `wip/` | throwaway in-progress |
| `STATUS.md` | current state — read first |

Put new work into DANS. Do not invent parallel top-level folders.
